# Plan: Ocawe → Octra интеграция

## 1. Streaming (`stream: true`)
SSE-поток от Ocawe к клиенту. Пользователь видит ответ токен за токеном.
- Начать с `/api/chat` — передавать `stream: true`
- Ocawe уже умеет, Octra просто не шлёт флаг

## 2. MCP Manager
Дать пользователю из UI управлять MCP-серверами.
- Ocawe: полный CRUD + каталог инструментов/ресурсов/промптов
- Octra: API-прокси на Ocawe + UI

## 3. Workflow Runs API
Запуск, отслеживание, пауза/возобновление раннов Canvas.
- Листинг, старт, resume, cancel, time-travel
- Canvas из редактора становится рантаймом

## 4. HITL (Human-in-the-Loop)
Приостановка воркфлоу для ввода пользователя.
- После появления работающих раннов Canvas

## 5. Triggers / Webhooks
HTTP-триггеры для воркфлоу, агентов, скиллов.
- Автоматизация для pay-юзеров
