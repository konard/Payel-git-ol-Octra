# Octra — MCP хостинг-платформа

## Проблема

Вайбкодеры и AI-юзеры — люди из разных сфер: дизайнеры, маркетологи, аналитики, менеджеры. Они хотят использовать AI агентов с инструментами, но настройка MCP сервера требует:
- аренды VPS
- SSH
- установки зависимостей
- написания JSON конфигов
- понимания портов, процессов, systemd

Это порог, который большинство не готово перешагивать. Они либо забивают, либо теряют дни на настройку.

## Решение: MCP-as-a-Service

Платформа, где пользователь получает **своего AI агента онлайн 24/7** без единой команды в терминале.

### Как это работает

1. **Регистрация** — заходит на сайт, вставляет API-ключ (Anthropic/OpenAI/etc.)
2. **Выбор скиллов** — на канве перетаскивает нужные MCP серверы (файлы, GitHub, поиск, БД, etc.)
3. **Подключение** — платформа сама разворачивает MCP серверы и связывает с агентом
4. **Использование** — пользователь получает готовый эндпоинт (SSE/HTTP) и может слать запросы агенту с инструментами

### Что дает платформа

- **Никакой аренды сервера** — всё работает на нашей инфраструктуре
- **Никакого SSH** — всё через браузер
- **Никакой установки** — скиллы подключаются в один клик
- **Круглосуточный доступ** — агент онлайн всегда
- **Быстрый доступ** — без VPN, без ssh-туннелей, просто URL и ключ
- **Визуальная канва** — видишь как агент соединен со скиллами, можешь менять конфиг мышкой

### Кому нужно

- **Вайбкодеры** — хотят AI с инструментами, но без танцев с бубном
- **Фрилансеры** — нужен AI помощник 24/7 под их задачи
- **Команды** — хотят расшарить одного агента на несколько человек
- **Все, кто устал настраивать MCP вручную**

## Чем отличается от существующих решений

- Не требует установки софта на стороне пользователя
- Гибкая визуальная настройка, а не редактирование JSON
- Хостинг включен — не нужно думать где запускать
- Ориентация на нетехнических пользователей

## Отказ от старой концепции

Старая Octra — софт-фабрика с иерархией агентов, Nix, сложным пайплайном — оказалась никому не нужна. Новая Octra решает реальную боль реальных людей: сделать MCP доступным для всех.
