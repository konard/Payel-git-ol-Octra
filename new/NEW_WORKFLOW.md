Ворк флоу бекенда:
Пользователь обращаеться к бекенду через api для получения ответа своего ранее
размещённого агента потом происходит поиск в базе данных она отдаёт данные этого агента 
и мы обращаемся к нему с пользовательским промтом получаем ответ и отдаём его пользователю 
это всё должно происходить довольно быстро что бы это сильно не отличалось от обычного вызова по api того же ии 
после чего возвращаем ответ пользователю

Перед работой мы создаём своё окружение (пользователь уже авторизован):
```json
{
  "user_id": "",
  "creating_environment": {
    "llm": [
      "api_key": "",
      "base_url": ""
    ],
    "agent": [
      "cli": ""
    ],
    "skills": [
      "id",
      ...
    ]
  }
}
```
После чего настраиваем cli агента (если он указан в конфиге) а именно скиллы и саму иишку (llm) 

После этого возвращаем:
```json
{
  "user_id": "",
  "api_key": "" 
}
```

Данные которые должен получать бекенд от пользователя:
```bash
curl "" \
  -H "octra-api-token: $OCTRA_API_KEY" \
  -H "Content-Type: application/json" \
  -X POST \
  -d '{
    "prompt": "",
    "skills": [
        "id",
    ]
  }'
```

принятие запроса -> поиск пользователя -> поиск его агента -> поиск сккиллов по id -> отправка запроса ии -> получение ответа -> отправка ответа пользователю
(никаких боссов менеджеров и воркеров сред разработки и всего прочего хлама)

ответ сервера:
```json
{
    "response": ""
}
```
