# Оплата и маржа

## Баланс пользователя

У каждого пользователя есть баланс в кредитах. С него списывается стоимость хостинга агентов.

Пользователь может размещать **несколько агентов**. Оплата всех агентов суммируется.

Баланс может уходить в **отрицательные значения** — это нормально. Пользователь пришёл зарабатывать, а не брать кредит и убегать.

### Стоп-механизм

Если баланс отрицательный — пользователь **не может запустить агентов** пока не покроет долг. Уже запущенные агенты не останавливаются (чтобы не потерять решение задачи), но новые сессии блокируются.

---

## Авто-оплата (Margin Call)

Пользователь настраивает **автоматическую оплату** — списание средств по расписанию:

- Каждый день
- Каждую неделю
- Каждый месяц
- Каждые полгода
- Каждый год

При наступлении даты оплаты система жёстко списывает средства за потреблённые ресурсы. Если баланс уходит в минус — это долг пользователя.

---

## Два режима маржи

### 1. Безлимитная маржа (Unlimited)

- Баланс может уходить в минус без ограничений
- Авто-оплата списывает сколько набежало, даже если баланс отрицательный
- Подходит пользователям, которые активно решают задачи и зарабатывают
- **По умолчанию для всех**

### 2. Безопасная маржа (Safe)

- Баланс не может опуститься ниже нуля (или заданной пользователем суммы)
- Когда баланс на исходе — оплачиваются только **самые часто используемые агенты** либо те, что пользователь отметил приоритетными
- Остальные агенты приостанавливаются
- Подходит консервативным пользователям

## Модели данных

### User (дополнительные поля)
- `balance` int — текущий баланс в кредитах
- `margin_mode` enum — unlimited / safe
- `safe_margin_limit` int — минимальная сумма (для safe mode)
- `auto_pay_interval` enum — day / week / month / half_year / year
- `auto_pay_day` int — день списания

### Transaction
- `id` uuid
- `user_id` uuid
- `type` enum — credit / debit
- `amount` int — в кредитах
- `reason` enum — registration / hosting / lefine_reward / topup / penalty
- `agent_id` uuid — опционально, за какого агента
- `created_at` timestamp

### Agent (для safe mode priority)
- `id` uuid
- `user_id` uuid
- `priority` int — порядок оплаты при ограниченном балансе
- `usage_stats` json — статистика потребления
