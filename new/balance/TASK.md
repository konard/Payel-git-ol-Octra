# TASK — Балансы, оплата и маржа

## Что нужно сделать

Добавить в бэкенд систему балансов, оплаты за ресурсы и маржинальной торговли (по аналогии с биржами).

---

## Суть

Мы хостинг AI агентов. Мы не берём деньги за количество запросов или токенов — мы берём за **потребление ресурсов** (CPU, память, диск) каждого Nix окружения. Пользователь платит только когда его агент активен. Простой, настройка, установка скиллов — бесплатно.

Пользователь может размещать **несколько агентов**. Стоимость всех суммируется.

---

## Кредитная система

- 1 кредит = 10 центов (10 кредитов = 1$)
- 100 кредитов бесплатно при регистрации
- Тратятся на оплату хостинга
- Пополнение: банковский счёт / криптовалюта / через LeFine

---

## LeFine интеграция — заработок

LeFine.pro — маркетплейс задач. Заказчики создают задачи с призовым фондом. Солверы решают — получают награду.

**Octra как солвер:** пользователь в пару кликов подключает агента к LeFine. Агент автоматически получает задачи, решает, отправляет решения, отслеживает статус.

Выигранные средства зачисляются в кредиты на баланс пользователя.

---

## Баланс

- Хранится у пользователя в поле `balance` (может быть отрицательным)
- Списывается за потреблённые ресурсы по расписанию
- Если баланс отрицательный — **нельзя запустить новых агентов**
- Уже запущенные не останавливаются (чтобы не потерять решение задачи)
- Долг нужно покрыть перед запуском новых сессий

---

## Авто-оплата (Margin Call)

Пользователь выбирает интервал списания:

- Каждый день / неделю / месяц / полгода / год

При наступлении даты — жёстко списываем стоимость ресурсов за период. Если баланс уходит в минус — это долг.

---

## Два режима маржи

### 1. Безлимитная маржа (Unlimited) — по умолчанию

- Баланс может уходить в минус без ограничений
- Авто-оплата списывает всё, даже если баланс отрицательный
- Подходит тем, кто активно решает задачи и зарабатывает

### 2. Безопасная маржа (Safe) — опционально

- Баланс не ниже нуля (или заданной суммы)
- При нехватке — оплачиваются самые частые/приоритетные агенты
- Остальные приостанавливаются

## Расчёт стоимости

```
standart_payment = int  // базовая фиксированная ставка

struct Payments(n int) {
    cheaper   = standart_payment - n%
    expensive = standart_payment + n%
}

нагрузка = get(user_id)  // CPU, память, диск
средняя_нагрузка = сумма_нагрузки_всех / N
процент = нагрузка / средняя_нагрузка * 100

if процент > 100 {
    платёж = Payments(процент).expensive  // дороже
} else {
    платёж = Payments(процент).cheaper   // дешевле
}
```

## Модели данных

### User — новые поля
- `balance` int
- `margin_mode` enum — unlimited / safe
- `safe_margin_limit` int — мин. сумма для safe
- `auto_pay_interval` enum — day / week / month / half_year / year
- `auto_pay_day` int — день списания

### Transaction
- id, user_id, type (credit/debit), amount, reason (registration/hosting/lefine_reward/topup), agent_id, created_at

### UsageMetrics
- user_id, date, cpu_seconds, memory_mb_hours, disk_mb, load_percent

### Agent — новое поле
- `priority` int — для safe mode
