# Балансы и монетизация

## Суть

Octra — не просто хостинг AI агентов, но и платформа для заработка. Любой пользователь может настроить агента и стать **солвером** на LeFine.pro — решать задачи за реальные деньги, не имея своего сервера.

---

## LeFine интеграция — заработок

LeFine.pro — это маркетплейс задач. Заказчики создают задачи, закидывая средства на счёт. Запускается аукцион — выбираются 3 лучших решения, заказчик выбирает одно.

**Octra как солвер:** пользователь в пару кликов подключает своего агента к LeFine. Агент автоматически:
- получает подходящие задачи
- решает их
- отправляет решения
- отслеживает статус

Пользователю не нужен VPS, SSH, настройка — всё уже работает на Octra.

Выигранные средства зачисляются в кредиты на баланс пользователя. LeFine считает награду, Octra отображает и хранит историю.

---

## Модель оплаты

**Без подписок.** Оплата зависит от реального потребления ресурсов сервера (CPU, память, диск), а не от количества запросов или токенов. Запросы к AI оплачивает сам пользователь (своего API ключа), Octra берёт только за хостинг.

### Как это считается

Вводится **фиксированная базовая ставка** (`standart_payment`). Она снижается или повышается в зависимости от нагрузки конкретного пользователя относительно средней нагрузки по всем пользователям.

```
standart_payment = int          // базовая ставка

// структура коррекции
struct Payments(n int) {
    cheaper   = standart_payment - n%   // понижение
    expensive = standart_payment + n%   // повышение
}

// получаем нагрузку конкретного солвера
selected_solver.load = get(user_id)    // CPU, память и т.д.

// общая нагрузка всех активных солверов
total_load = solver1 + solver2 + ... + solverN

// средняя нагрузка
average_load = total_load / N

// процент отклонения нагрузки конкретного солвера от средней
load_percent = selected_solver.load / average_load * 100

// финальный платёж
if load_percent > average_load {
    // потребляет больше среднего — платит больше (expensive)
    payment = Payments(load_percent).expensive
} else {
    // потребляет меньше среднего — платит меньше (cheaper)
    payment = Payments(load_percent).cheaper
}
```

### Принципы
- Платишь только когда агент активен и потребляет ресурсы
- Нет платы за простой, настройку, установку скиллов
- Нагрузка считается не по запросам, а по CPU/памяти/диску Nix окружения
- Чем меньше потребляешь относительно других — тем дешевле

## Кредитная система

1 кредит = 10 центов (10 кредитов = 1$). Нужно чтобы избежать дробных чисел.

- **100 кредитов бесплатно** при регистрации
- Тратятся на оплату ресурсов хостинга
- Не списываются за простой агента
- Не списываются за настройку окружения или установку скиллов
- Пополнение: банковский счёт / криптовалюта / через LeFine

## Модели данных

### Balance
- UserID
- Credits (int) — текущий баланс в кредитах
- UpdatedAt

### Transaction
- ID
- UserID
- Type (credit / debit)
- Amount (в кредитах)
- Reason (registration / hosting / lefine_reward / topup)
- CreatedAt

### UsageMetrics
- UserID
- Date
- CPU (секунды)
- Memory (MB-часы)
- Disk (MB)
- LoadPercent (float)
